# NextStep／下一步 · 界面原型

AI 帮你整理杂事、排优先级、规划路径，并直接代办能代办的部分；需要你参与时，只给一个清楚的下一步。

本原型只做界面和演示交互：AI 回复、草稿、事项和进展全部是本地模拟数据（规则见 `src/lib/mockAI.ts`），不连接模型、后端或任何账号，也不会发送任何消息。

## 启动

```bash
npm install
npm run dev
```

打开 http://localhost:5173 （端口被占用时 Vite 会自动换一个，终端里会显示实际地址）。

构建检查：`npm run build`

## 三条演示路径

右上角的“演示数据”菜单可以切换场景，也可以“重置演示”恢复初始数据（只清除本应用自己的本地数据）。

1. **普通启动**：首页 → AI 先帮我做 → 在抽屉里查看、编辑、复制草稿 → 采用这版 → 出现“完成了”横幅（可撤销，可反馈难度），下一步自动就位；进展页能看到行动和成果。
2. **低精力／卡住**：演示菜单选“低精力／卡住” → 卡住了 → 选原因：
   - 这一步太大：行动缩小为“先确认一段已有经历”，核对几项信息（不对可以直接改），点“没问题，记一小步”记一次推进；
   - 不知道怎么做：给出可直接修改的第一段，保存即推进；
   - 容易分心：进入只有当前步骤的简洁视图。
3. **中断后回来**：演示菜单选“中断后回来” → 首页显示“接上次：项目经历已改到这里”和已有草稿 → 接着改（光标停在上次的位置）→ 采用。
   不用演示菜单也能看到：在草稿里改几个字后关掉抽屉，回到首页就会出现“接上次”，停在你离开的那一条。

## 交互细节（可用性优化后）

- **一个主按钮**：每屏只有一个实心主按钮；手机上主按钮整行宽、在拇指够得到的位置。
- **进度**：行动卡、“我来做”、简洁视图、规划页都显示进度。说法会随进度变化：刚开始时说已经做了几件，快完成时说还差几件。进展页有累计推进次数，只增不减。不做总完成率，也不做连续打卡。
- **收工**：选“今天到这里”后，首页列出今天推进了什么，并写清明天从哪开始。
- **约个时间**：现在不方便时，行动卡最下面可以约个时间，首页会写清“到了几点，先做哪一步”，还能加到日历（生成 .ics 文件）。时间选项会绕开你自己定的休息日和休息时间。到点后提示一次，过了就不再提，不做“逾期”提醒。
- **看改动**：草稿抽屉里可以切到“看改动”，新增的部分有底色，删掉的有删除线；原文里没有的数字会单独提醒，采用前方便核对。
- **计时（可选）**：简洁视图里可以打开“计时”，只显示已专注几分钟，不倒计时。
- **新手引导**：第一次打开时，行动卡下面有三句话的引导，演示菜单里可以再看一遍。
- **拆任务：系统先拆，你能改**：待整理里的事加入规划时，系统先拆成 3 步，第一步写得具体、10–15 分钟能做完，并标着“AI 拆的，可以改”。步骤可以改说法、删、加、调顺序，也可以让 AI 重新拆，或“拆得更细”（在最前面加一个 2 分钟的起步动作）。
- **AI 只做它能做的**：改简历、写消息、判断投不投，主按钮是 AI；修车、交电费这类，主按钮是“开始第一步”。采用拆解会写进步骤，不会把事情标成完成；采用消息只算写好了消息，发出去才算完成。
- **重新规划**：改了近期方向（换了一类方向）时，系统会拟一条新的阶段路线让你确认，可以撤销。
- **都能撤销**：采用草稿、标记完成、移动事项、全部按建议放好，都可以撤销。
- **返回键**：手机返回键先关掉抽屉、助手或简洁视图，再在页面之间后退；底部抽屉可以下拉关闭。
- **低精力**：首页直接给出“最小的一步”；卡住后缩小的行动不需要全部勾完才能确认。
- **休息边界**：过了你在“维持安排”里定的时间（示例是晚上 9 点半），首页会提醒可以收工，可以选择“我还想做一点”。
- **键盘与读屏**：抽屉和浮层会接住焦点、Esc 关闭、关闭后焦点回到原处；文字对比度满足 WCAG AA。

详细的审查结论和每项改动的依据见 `UX-优化说明.md`。

## 结构

- `src/data/seed.ts`：三个演示场景的初始数据
- `src/state/store.tsx`：统一状态（任务、阶段、成果、时间线、对话），存 localStorage
- `src/lib/mockAI.ts`：模拟 AI 的全部规则（草稿、整理建议、卡住调整、助手关键词）
- `src/pages/`：现在 / 规划 / 待整理 / 进展
- `src/components/`：布局、共用详情抽屉、助手侧栏、简洁视图
- `src/lib/hooks.ts`：对话框焦点管理、下拉菜单键盘操作、底部抽屉拖拽关闭等交互工具
- `src/lib/progress.ts`：进度文案规则（小面积效应、起点进度、最后一步），注释里写了依据
- `src/lib/plan.ts`：约个时间（常用时间、口语化时间、用户规矩、.ics 日历文件）
- `src/lib/diff.ts`：草稿“看改动”的对比算法（中文按字、英文按词，零碎片段合并；列表按条目比较）
